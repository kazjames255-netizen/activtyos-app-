Fixed

Malformed JSON crashed the server (500, not 400)

Any route receiving a broken JSON body returned a raw 500 instead of a clean validation error. Root cause was shared error middleware (server/src/index.ts) missing a branch for body-parser's JSON syntax error. Fixed, verified against three routes, no regressions.

Fixed

Double-cancel could reopen a refund replay guard

Cancelling an already-cancelled booking was silently accepted again, and a chained cancel → approve-refund → cancel-again sequence could reset refund state and reopen the replay guard against duplicate refund approval. Fixed with the same guard pattern already used on refund-approve.
