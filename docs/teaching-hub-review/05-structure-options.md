## Recommendation
**Target = Option A borrowing C's global Assign sheet** (beats or ties today on all 8 scenarios; loses on none of the top 5 jobs). It is an XL change and cannot be built safely in one night alongside everything else, so it is delivered in **stages**:
1. **Tonight (Option B moves + fixes):** the changes in `06-proposals.md` — truthful numbers, one-tap End broadcast, child Home that answers "what do I do now", accessibility fixes, tab merge 11 → 9 (Placement folds into Quizzes as "Starting quizzes"; Tools moves inside Lessons as a launcher; Messages named consistently), curriculum map collapsed by default.
2. **Next:** one Assign sheet; one Mark queue; student profile as the hub for a child.
3. **Then:** Today/Library/Teach/Progress/Messages navigation (Option A) once (1) and (2) are proven; age-banded family navigation (KS1 three icons; KS2/KS3–4 Today · Learn · Progress · Tutor).
