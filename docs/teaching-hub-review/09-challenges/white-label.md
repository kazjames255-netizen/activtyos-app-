# 09 Challenge: white-label owner

Scope: proposals P-01..P-13 and the 05 staged plan, tested against (a) football camp, no maths/English; (b) centre, 6 tutors; (c) single tutor; (d) franchise seeing head-office content; (e) tenant with custom kinds/year groups/subject names. Code-checked: `lib/hubConfig.ts`, `lib/accessMap.ts`, `lib/brand-theme.ts`, `components/shell/ParentBrandTheme.tsx`, `features/learninghub/subjectColour.ts`, `panels.tsx`, `SetupApp.tsx` (tab "hub", ~L2513).

## Facts that shape every verdict
- Hub is opt-in per tenant (`OPT_IN_FEATURES`, accessMap L50); `settings.hub` (HubSettings) is already the tenant lever: questionKinds, passMark, yearGroups (free text, default Reception..Year 13), masteryBands, subjectColours. There is NO setting for: subjects taught, tabs shown, hide Tools, hide curriculum, tutor-facing vocabulary.
- Tenant accent is applied ONLY by `ParentBrandTheme` (custdash portal), overriding `--brand-2/--brand/--brand-strong/--brand-ink/--brand-soft/--brand-line` from one hex via `brandVars`. Tutor/operator hub runs on `globals.css` defaults (`--brand-2:#2f6bd8`). `brandVars` derives `--brand` by darkening 20%, with no contrast guarantee (`brandAccent()` does check contrast but the hub does not use it). So a pale-yellow tenant gets white-on-yellow buttons in the family hub today (LearningHubApp uses `text-white` on `var(--brand-2)` gradients).
- Subject colours: `--sub-<slug>` overrides plus baked-in fallback and a ">=4.5:1 ink" already designed. Default palette matched by regex on maths/english/science names (subjectColour.ts L37), fine as a fallback only.
- Data-driven already: subjects (`subjectsOf(topics)`), year groups, band labels, question kinds. Hard-coded: 11 tabs (`TAB_ORDER`), curriculum card (NC 2014, UK), Tools registry subjects, "Year N" parsing in HomeworkForm L117 (`year ${pack.year}`), "Teaching Hub"/"My Classroom" strings (no i18n, R-10).
- Franchise: head-office content read-only, own students only (`hubCore.ts`); no "From head office" badge in the UI.

## Cross-cutting: where a tenant lever beats a global default
1. Subjects we teach (S1): drives P-02 count, P-08 chips, P-12 subject filter, P-09 curriculum. Today "subjects" are inferred from content and from Oak import.
2. Feature visibility (S2): tabs and blocks (Tools, Flashcards, Starting quizzes, Curriculum, Live). One switch set replaces the P-08/P-09/P-10 global reshuffles and gives (a) and (c) an immediate quiet hub, while keeping the global default modest.
3. Terminology/threshold set (S3): hub name, "students" noun, session vs lesson, quiet-days threshold (14), broadcast idle timeout (45 min), child tone. Small, string-only, satisfies (a), (e) and the English-only concern without full i18n.

## Franchise (d) specifics
- Head-office content is read-only; new copy and P-10 need a visible "From head office" badge; P-12 first-run for a franchise tutor should offer head-office lessons first. Tenant settings for hub tabs/subjects are per franchise ("keeps its own Setup") so a franchise setting hides only its own view; head-office settings should be the default a franchise inherits until it overrides.

## Ordering advice
P-07's token mechanism (`--on-brand`, apply brand vars to tutor hub, tests over extreme accents) should land before other visual changes, otherwise every new brand-coloured element (P-03 card, P-06 Today) inherits the same defect for non-blue tenants.
