# P-02 Numbers that agree

**What/why.** The Home header counted every note as a "lesson", showed a topics sub-line and a Worksheets tile that did not match what a tutor sees. Now only real lessons and subjects that have lessons are counted, with one summary line.

**Files.** `server/src/routes/learningHub.ts` (`/notes/counts`), `features/learninghub/types.ts` (`NoteStats`), `features/learninghub/HubHero.tsx`.

**Before -> after.**
- Server: `/notes/counts` gains `lessons` (visible notes with `(isLesson || oakKey) && kind !== "board"`) and `lessonTopicIds`. All existing fields unchanged; no `NoteRow` change, no snapshot version bump.
- Hero: Worksheets tile and the "N topics" sub-line deleted; grid 4 -> 3 columns; Lessons = `lessons` (falls back to `total` on an older server); Subjects = distinct subjects of topics that hold a lesson; new line "N students - N lessons - N subjects" (students only for tutors).
- Saved Hide/Show (`aos.hero.learninghub`) still honoured; the button title now says "Hide/Show the numbers"; the settings gear is untouched.
- Counts remain scoped by the Lessons year filter, as before.

**Revert.** `git revert` the commit (server field is additive; the old client ignores it).

**Tests.** Root and server `tsc`; curl of `/notes/counts` on a throwaway tutor; see final report.
