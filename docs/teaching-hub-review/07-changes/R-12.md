# R-12 Printable progress report (with the parent verdict and plain-language pass)

**What / why.** Parents asked for something they can keep or show a school (P1/P2 journals). Parent Progress now has a "Progress report" button (one tap). It opens a paper-style page for the chosen child only: subjects with stars in words ("3 of 3 stars") and the tutor's own level name, homework handed in vs set (last 3 months), and next steps. "Print or save as PDF" calls `window.print()`; `@media print` hides the app and the toolbar. No PDF service, no email, no new API.

**Same commit set, parent Home.** The top card now leads with one verdict line per chosen child, from existing data only: "Ava: 1 homework overdue" (red, taps to Homework), "Ava: All done this week" (nothing to do and something handed in this week, taps to Progress), otherwise "Ava: On track". Jargon on parent screens is replaced through one string table: "Take the placement test" becomes "Take the starting quiz", "Mastery snapshot" becomes "How they're doing", "mastery" becomes "level", "Coverage" becomes "Topics tried", "placement-test starting point" becomes "starting quiz result". Network errors on parent Progress use `friendlyError` (P-05/P-13) with "Try again". "Starting quiz" is kept. Tutor and child wording is unchanged.

**Files.** `features/learninghub/family/parentCopy.ts` (new string table), `progress/ProgressReport.tsx` (new), `ProgressPanel.tsx`, `progress/ProgressView.tsx`, `progress/Attainment.tsx`, `home/StudentHome.tsx`, `e2e/review/parent-report.spec.ts`.

**Privacy.** Fetches only the chosen child's `/mastery` and `/homework`; renders no tutor notes, no free-text feedback, no other children. Spec asserts the other fixture children's names never appear.

**Revert.** `git revert` the two commits. Frontend only.

**Tests.** `npx tsc --noEmit` clean; `e2e/review/parent-report.spec.ts` at 390 and 1440 including print emulation. Screenshots in `screenshots/after/parent/`.

**Not done.** Notifications/emails (R-9, R-14); a verdict line for each of several children at once; a real term calendar.
