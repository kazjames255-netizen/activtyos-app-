# R-5 Per-child support profile (+ read-aloud)

Builder I. Branch `teaching-hub-redesign`. Commits: `hub: read-aloud`, `hub: R-5 support profile`.

## What changed
- **Read-aloud** (`features/learninghub/speak.tsx`): `speakText`/`useSpeak`/`<SpeakButton>` over `window.speechSynthesis`, en-GB voice, rate 0.9, no auto-play, cancelled on unmount, one utterance at a time, rendered only when speech exists (SSR-safe via `useSyncExternalStore`), min 44px, `aria-label` + `aria-pressed`. On the kid next-step card (56px), each quiz question prompt (QuestionView) and the result headline (ResultBanner).
- **Support profile** on the enrolment: optional `support {noTimer, extraTimePercent 0|25|50, calm, readAloudDefault, textSize normal|large}`. Pure logic in `features/learninghub/support.ts` (`cleanSupport`, `effectiveLimitMins`), selftest `server/src/supportSelftest.ts`.
- **Server**: `POST/PUT /students` accept `support` (strict zod, merged, default profile is not stored); `requireEdit` + franchise scope already gate both routes, so a family can never write it. `GET /students` returns it to tutors, and read-only on a parent's own children. Re-enrol and family-invite re-enrol carry it over. **Timed-quiz enforcement**: `POST /assessments/:id/attempts` snapshots `timeLimitMins = effectiveLimitMins(quiz limit, child.support)` onto the attempt, so the deadline, lateness and resume checks all use the child's limit (noTimer = untimed, +25/+50% rounded up to a whole minute).
- **Tutor UI**: one compact "Support" fieldset (`SupportSection.tsx`) in the Enrol dialog and in Students > Edit details.
- **Child player**: `useSupport()` (FamilyContext). Calm removes streak chip (StudentHome), lesson streak/XP pills and confetti; `#learning-hub[data-calm]` kills all animation/transition; large text = `zoom: 1.15`; quiz list/intro show the child's own limit; `readAloudDefault` makes the question speaker read the options too. `prefers-reduced-motion` now applies to all of `#learning-hub` (globals.css).

## Additive schema change (no migration)
`hubEnrolments/{tenant}__{child}.support` optional map. Absent = today's behaviour; old clients ignore it; old docs need no backfill.
