# P-01 End a forgotten broadcast

**What/why.** Tutors could only "Leave" a remote lesson, so forgotten sessions stayed live for 6 h and pestered families. Now the tutor banner has "End lesson" (Undo window of 6 s, no confirm dialog) calling the existing `/end`; idle expiry is 90 min and child heartbeats no longer keep a session alive.

**Files.** `server/src/routes/hub/remoteSyncApi.ts`, `features/learninghub/remotesync/TutorLiveBanner.tsx`, `JoinRemoteSyncBanner.tsx`.

**Before -> after.**
- STALE_MS 6 h -> 90 min. Child heartbeat no longer writes `updatedAt` (attendance only). Real child live-answer writes and all tutor writes still bump it.
- liveAnswer/heartbeat already return 409 `lesson_closed` when not live (unchanged, verified in code).
- Tutor: End lesson -> "Ending ... Undo" for 6 s -> `/end` is sent only after the window; failure shows an inline error.
- Child: dialog now reads "Your tutor has finished the lesson." (banner already hides for non-live sessions).
- No new doc fields.

**Revert.** `git revert` the commit; or set STALE_MS back and re-add `updatedAt: now` to the heartbeat update.

**Tests.** tsc (no errors in touched files); API curl and Playwright smoke - see final report.
